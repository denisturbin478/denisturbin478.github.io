The organising idea

Build around responsibilities.

I mapped the role-specific journeys before designing the screens. Pipeline management, document collection and borrower tasks became connected workflows with their own hierarchy. The proposed integration with an existing Loan Origination System keeps those workflows close to the tools a mortgage team already uses.

Experience flow

Follow the application, not the menu.

The loan lifecycle used to organise the proposed experience. Each role joins the journey at a different point.

Design coverage

Three journeys around the same application.

The brief names four loan phases: lead intake, underwriting, document collection and closing. Role-specific journeys were mapped for officers, processors and borrowers, alongside manager-facing dashboard information. The deliverable is an interface design covering that workflow.

Project context

The established deliverable is UX/UI design. Production implementation and launch are not established.

Designing the document journey

The proposed borrower portal includes document upload, e-signing and application progress. Document workflows use checklists, status indicators, version history and reminder states to give each role a clearer view of what happens next.
