FigmaGoogle AI Studio

The Brief

Design a CRM ecosystem for Sabsus, a restaurant technology company. The platform needed to cover sales pipeline management, client profiles, a POS system interface, and internal dashboards for the sales team. The client wanted a dark, modern UI with a distinctive visual identity.

The Approach

Started by mapping the core workflows: lead → demo → onboarding → active client. Then designed each module in Figma, building a component system with dark backgrounds and purple accent colors that could scale across the entire product. Used Google AI Studio during the exploration phase.

Key Features

Sales dashboard — real-time metrics, deal velocity, and team performance in a single view Pipeline management — visual deal stages with drag-and-drop, filters, and bulk actions Client profiles — unified view of restaurant clients with contract details, support history, and usage data POS system interface — designed the point-of-sale module that restaurant staff interact with daily Dark UI with purple accents — a cohesive design system that gives the product a premium, distinctive feel

The Result

A full CRM design system for a restaurant tech company that covers the entire client lifecycle. The dark UI with purple accents became a core part of the Sabsus brand identity.
